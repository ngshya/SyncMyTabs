# Store assets

Marketing/listing images for the Chrome Web Store (and, where the same
dimensions apply, AMO). Not used by the extension itself at runtime — these
are only for the store listing.

| File | Size | Notes |
|---|---|---|
| `screenshot-1-overview-1280x800.png` | 1280×800 | Composite: the full settings page (`options.html`) as the main view, with the compact toolbar popup (`popup.html`) inset top-right, populated with realistic sample data. Meets the Chrome Web Store's 1280×800 screenshot spec (PNG, no alpha channel). |

Generated by loading the real, unpacked extension in Chromium (via
Playwright) with sample storage data seeded in, screenshotting `popup.html`
and `options.html`, then compositing both into a single branded frame — not
hand-drawn mockups. Regenerate the same way if the UI changes enough to make
this stale; there's no script checked in for it since it's a one-off, not
part of the build.
