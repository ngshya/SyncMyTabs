# Store assets

Marketing/listing images for the Chrome Web Store (and, where the same
dimensions apply, AMO). Not used by the extension itself at runtime — these
are only for the store listing. Upload order: see `STORE_LISTING.md`.

| File | Size | Notes |
|---|---|---|
| `screenshot-2-newtab-dark-1280x800.jpg` | 1280×800 | The new tab page, dark theme: bookmarks bar, clock, search box, open tabs by window and tab group (one folded), recently auto-archived tabs by day. JPEG (no alpha channel). |
| `screenshot-3-newtab-light-1280x800.jpg` | 1280×800 | The same, light theme. |
| `screenshot-4-newtab-matrix-black-1280x800.jpg` | 1280×800 | The same, black theme with the optional Matrix rain. |
| `screenshot-5-newtab-matrix-dark-1280x800.jpg` | 1280×800 | The same, dark theme with the optional Matrix rain. |
| `screenshot-1-overview-1280x800.png` | 1280×800 | Composite: the full settings page (`options.html`) as the main view, with the compact toolbar popup (`popup.html`) inset top-right, populated with realistic sample data. Meets the Chrome Web Store's 1280×800 screenshot spec (PNG, no alpha channel). |

The four new tab page shots are generated by `npm run screenshots -- <dir>`
(they land in `<dir>/store/`: the built extension in headless Chromium with
a fake web and sample tabs, groups, archived tabs and bookmarks bar, page
zoomed to 80% so everything fits in 1280×800) — copy them here when the
page changes.

The overview was made by loading the real, unpacked extension in Chromium
(via Playwright) with sample storage data seeded in, screenshotting
`popup.html` and `options.html`, then compositing both into a single
branded frame — not hand-drawn mockups. There's no script checked in for it
since it's a one-off, not part of the build.
