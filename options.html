SyncMyTabs

Assign a name to this device. It will be used to tag the tabs you open so other devices know where they came from.

Profiles

Organize your open tabs into separate profiles (e.g. "default", "work", "school"). Only one profile is active at a time on this device, and automatic sync only ever happens for the active profile — profiles stay fully independent of each other.

Sync

Opening or closing a tab is detected right away and written immediately; this interval only controls how often this device double-checks itself and other devices in the background (in minutes).

When restoring tabs from another device, open them as lightweight placeholders that don't load from the network until you actually view each tab. Saves memory and bandwidth when restoring many tabs.

Cleanup

A tab is only removed from the shared bookmarks once every device that ever had it open has closed it. If a device is uninstalled or never comes back, this safety net deletes its stale entries after the chosen number of days, so a "ghost" tab doesn't linger forever. A tab you keep genuinely open never goes stale — it's refreshed automatically well before the deadline.
